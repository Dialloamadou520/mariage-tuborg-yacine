# Ambiance Musicale - Mariage Tuborg & Yacine

Ce dossier héberge le morceau musical d'accueil des invités.

### Morceau recommandé :
- **Titre** : *Daman Bannex*
- **Artistes / Troupe** : *Troupe Obree Daman*
- **Nom du fichier à placer ici** : `daman-bannex.mp3`

### Fonctionnement :
1. Déposez votre fichier `daman-bannex.mp3` dans ce dossier (`assets/audio/daman-bannex.mp3`).
2. Le lecteur audio sur le site détectera et lira directement ce fichier MP3.
3. Si le fichier n'est pas encore présent lors de vos tests, un synthétiseur acoustique intégré (Web Audio API) génère automatiquement une douce mélodie de cordes/kora pour que la musique fonctionne immédiatement dans votre navigateur.
